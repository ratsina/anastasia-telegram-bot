# Telegram-бот Анастасии

Бот собирает заявки на массаж и ЛФК, выдаёт два комплекса упражнений, проверяет подписку на канал и отправляет готовые карточки в отдельную Telegram-группу. npm-зависимости не требуются.

## Запуск

```powershell
.\start-bot.cmd
```

Для остановки нажмите `Ctrl+C`.

Если Telegram API временно недоступен, бот не завершится: он будет повторять подключение автоматически с интервалом до одной минуты.

На этом компьютере команда запуска использует локальный HTTP-прокси `v2RayTun` по адресу `127.0.0.1:10801`. Перед запуском убедитесь, что `v2RayTun` включён.

## Подключение группы заявок

1. Добавьте бота в группу.
2. Отправьте в группе команду `/id`.
3. Скопируйте показанное число целиком, включая знак минус.
4. Вставьте его после `ADMIN_CHAT_ID=` в файле `settings.env`.
5. Перезапустите бота.

Ссылка-приглашение группы не содержит доступный боту числовой `chat_id`, поэтому команда `/id` — самый простой способ его получить.

## Проверка подписки

Добавьте бота администратором канала `@anastasia_lfk_massage`. Иначе Telegram не позволит надёжно проверять подписку других пользователей.

## Замена заглушек

Все заменяемые значения находятся в `settings.env`:

- `COMPLEX_1_URL` и `COMPLEX_2_URL` — ссылки или Telegram `file_id`;
- `COMPLEX_1_MODE` и `COMPLEX_2_MODE` — `link` либо `video`;
- `ADMIN_CHAT_ID` — ID группы заявок.

Токен бота и настройки персональных данных находятся в игнорируемом Git файле `.env`:

- `PRIVACY_POLICY_URL` — обязательная публичная ссылка на Политику;
- `PRIVACY_POLICY_VERSION` и `PRIVACY_CONSENT_VERSION` — версии Политики и согласия;
- `PRIVACY_POLICY_DATE` — дата редакции Политики;
- `PRIVACY_OPERATOR_NAME` — полное ФИО Оператора;
- `PRIVACY_CONTACT_EMAIL` и `PRIVACY_CONTACT_TELEGRAM` — контакты для обращений и отзыва согласия.

Исходный текст Политики находится в `docs/privacy_policy.md`. В Telegram бот не отправляет этот длинный текст: команда `/privacy` и кнопка согласия открывают опубликованную страницу. Команда `/delete_data` сообщает контакт для отзыва согласия или запроса удаления данных.

После изменения текста повторно опубликуйте эту же страницу командой:

```powershell
.\publish-privacy.cmd
```

Скрипт обновит существующую страницу и сохранит актуальную ссылку в `.env`. Пример настроек без секретов находится в `.env.example`.

## Источники заявок

Бот сохраняет параметр ссылки `/start`. Например, ссылка вида `https://t.me/ИМЯ_БОТА?start=instagram_reels_15` добавит в карточку источник `instagram reels 15`. Параметр, начинающийся с `complex`, сразу открывает ветку бесплатного комплекса.
